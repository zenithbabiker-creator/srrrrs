# خطة تطبيق نظام الطباعة المباشرة الصامتة (Silent Direct Printing) وتخطي الطابعات الوهمية

خطة هندسية لتفعيل الطباعة الصامتة الفورية لفواتير المبيعات وأوامر التسليم في تطبيق شركة NOSSER، مع توجيه الفاتورة تلقائياً إلى الطابعة الفيزيائية الحقيقية المتصلة بجهاز المستخدم وتخطي طابعات PDF/XPS الوهمية لمنع ظهور نافذة "Save Print Output As".

---

## مراجعة المستخدم والقرارات المعتمدة

> [!IMPORTANT]
> تم اعتماد تفضيلات المستخدم بناءً على الإجابات التوضيحية السابقة:
> - **نمط الطباعة**: طباعة صامتة وفورية 100% بمجرد الضغط على زر "طباعة فاتورة مبيعات" أو اختصار `Ctrl + P` بدون أي نوافذ حوارية أو استئذان.
> - **إدارة الطابعات الوهمية**: الفحص الذكي لكافة الطابعات المعرفة في النظام، وتخطي أي طابعة افتراضية وهمية (مثل `Microsoft Print to PDF` و `XPS` و `OneNote` و `Fax`)، والتوجه فوراً لأول طابعة فيزيائية فعلية متصلة بالجهاز.
> - **بيئة التنفيذ**: تحديث محرك الطباعة في تطبيق بايثون المكتبي (`PySide6` / `nasser_company_app.py` و `pysideScriptGenerator.ts`) ومزامنة واجهة الويب (`printDocument.ts` و `DeliveryOrderModal.tsx`).

---

## 1. نظرة عامة والهدف الأساسي

- **ما الذي يقدمه التعديل**: القضاء التام على مشكلة ظهور نافذة "Save Print Output As" وحوارات الحفظ المزعجة عند طباعة الفواتير في بيئة العمل، بحيث تخرج الورقة فوراً من درج الطابعة بمجرد النقر على الزر.
- **الفئة المستهدفة**: مسؤولو المبيعات، أمناء المخازن، والمحاسبون الذين يطبعون عشرات الفواتير يومياً ويحتاجون إلى سرعة فائقة دون خطوات حفظ إضافية غير مرغوبة.
- **القيمة المضافة**: تجربة مستخدم سلسة وعملية في نقاط البيع (POS) وإدارة المخازن، مع ضمان بقاء البيانات مسجلة حصرياً في قاعدة بيانات النظام بدون ملء القرص بملفات PDF مبعثرة.

---

## 2. تجربة المستخدم والتصميم البصري

### مسار المستخدم (User Flow)
1. يفتح المستخدم تفاصيل الفاتورة أو أمر التسليم في شاشة `DeliveryOrderModal`.
2. يضغط المستخدم على زر **"طباعة فاتورة مبيعات (Ctrl + P)"** أو يضغط الاختصار من لوحة المفاتيح.
3. يقوم النظام فورياً ودون أي تأخير بما يلي:
   - فحص قائمة الطابعات المثبتة في الويندوز.
   - التحقق من الطابعة الافتراضية، وإذا كانت طابعة وهمية (`Microsoft Print to PDF` مثلاً)، ينتقل النظام تلقائياً إلى أول طابعة حقيقية جاهزة (مثل HP, Canon, Epson, Xprinter, Thermal POS Printer).
   - إرسال الأمر بوضع `QPrinter.NativeFormat` مباشرة إلى الطابعة.
   - إظهار شريط إشعار بصري أنيق في الواجهة: `تم إرسال الفاتورة مباشرة إلى الطابعة: [اسم الطابعة] 🖨️`.
   - لا تظهر أي نوافذ منبثقة أو نوافذ طلب حفظ للملفات.

### المؤشرات التفاعلية
- تغذية راجعة فورية على زر الطباعة تفيد بنجاح الإرسال.
- استمرار إتاحة المعاينة التامة للفاتورة داخل النافذة قبل الطباعة.

## 3. القرارات التقنية والمفاضلات الهندسية

### القرار 1: اكتشاف وتصفية الطابعات الفيزيائية في PySide6
- **النهج المتبع**:
  - استدعاء `QPrinterInfo.availablePrinters()` و `QPrinterInfo.defaultPrinter()`.
  - تطبيق قائمة استبعاد ذكية (Blacklist Filter) تحتوي على الكلمات الدلالية للطابعات الوهمية:
    `['pdf', 'microsoft print to pdf', 'xps', 'onenote', 'fax', 'writer', 'virtual', 'cuteftp', 'do-pdf', 'nitro']`.
  - إذا كانت الطابعة الافتراضية طابعة حقيقية، يتم اعتمادها فوراً.
  - إذا كانت الطابعة الافتراضية وهمية، يتم البحث في قائمة الطابعات المتاحة عن أول طابعة لا تطابق قائمة الاستبعاد وتعيينها كهدف مباشر.
  - في حال لم تكن هناك أي طابعة حقيقية متصلة مطلقاً، يتم التعامل بلطف مع النظام وتنبيه المستخدم لتوصيل طابعة فيزيائية بدلاً من الوقوع في فخ الحفظ العشوائي.

### القرار 2: الطباعة المباشرة الصامتة (Direct Silent Print)
- **النهج المتبع**:
  - إلغاء ظهور `QPrintDialog` تماماً في تدفق الطباعة الافتراضي.
  - استخدام `QPrinter(target_printer_info, QPrinter.PrinterMode.HighResolution)` مع ضبط `printer.setOutputFormat(QPrinter.OutputFormat.NativeFormat)`.
  - استدعاء `page.print(printer, callback)` المدمج في `QWebEnginePage` في PySide6 الذي يطبع مباشرة للـ QPrinter المخصص دون وسيط PDF خارجي.
  - توفير مسار احتياطي قوي في حال الحاجة عبر `QTextDocument.print_(printer)`.

### القرار 3: التوافق بين تطبيق الويب وسطح المكتب
- **النهج المتبع**:
  - في تطبيق سطح المكتب، يرتبط أمر الطباعة الصامت بمحرك Qt مباشرة عبر إشارة `printRequested`.
  - في تطبيق الويب، يتم تحسين معالجة `window.print()` وتوفير كلاسات CSS للتحكم في مقاس الصفحة ومنع الانقسامات الخاطئة، مع توجيه إرشادي ذكي لمستخدمي المتصفح العادي.

## 4. البنية التقنية ومخطط تدفق البيانات

```
┌────────────────────────────────────────────────────────┐
│               واجهة المستخدم (React UI)                 │
│      زر "طباعة فاتورة مبيعات" أو اختصار (Ctrl + P)      │
└──────────────────────────┬─────────────────────────────┘
                           │ window.print()
                           ▼
┌────────────────────────────────────────────────────────┐
│            محرك QWebEnginePage (PySide6)               │
│               إشارة printRequested                      │
└──────────────────────────┬─────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────┐
│            محرك فحص وتصفية الطابعات الذكي              │
│       - فحص QPrinterInfo.defaultPrinter()             │
│       - تصفية طابعات PDF/XPS الوهمية                    │
│       - اختيار أول طابعة فيزيائية متصلة بالنظام        │
└──────────────────────────┬─────────────────────────────┘
                           │ Target Physical Printer
                           ▼
┌────────────────────────────────────────────────────────┐
│     إرسال صامت فوري (QPrinter.NativeFormat)             │
│            page.print(printer, callback)               │
│          سحب الورق والطباعة الفيزيائية فوراً            │
└────────────────────────────────────────────────────────┘
```

### خطة الملفات المراد تعديلها عند الاعتماد:
1. `nasser_company_app.py`: تحديث دالة `print_function`، وإضافة دالة `resolve_physical_printer` للتصفية الذكية للطابعات وإرسال الأمر صامتاً 100% إلى الطابعة الفيزيائية بوضع `NativeFormat`.
2. `src/lib/pysideScriptGenerator.ts`: تضمين نفس كود الطباعة الصامتة الذكي في مولد سكريبت بايثون وتطبيق سطح المكتب لضمان تحديث الحزمة عند تصديرها.
3. `src/utils/printDocument.ts`: تدعيم معالجة الطباعة وإشعار المستخدم بالطابعة النشطة.
4. `src/components/DeliveryOrderModal.tsx`: تحسين تفاعل زر الطباعة وعرض حالة الإرسال للطابعة.
